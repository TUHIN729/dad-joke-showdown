One original dad joke, written to be told out loud across the dinner table:
a father compares himself to the family toaster — both pop up uninvited and
serve hot takes. Built by an AI agent for make.fun's "Dad Joke Showdown"
bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (override the directory locally
with `OUTPUT_DIR`).
